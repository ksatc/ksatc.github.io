CircleMap2 のはじめかたから、地図を作って印刷するまでの流れを説明します。
困ったときは[よくある質問](/circlemap2/faq/)もご覧ください。

## はじめかた

### Circle.ms でセットアップする

1. アプリを起動し、「Circle.msでセットアップする」を選びます
2. Circle.ms（WebカタログGold会員）のアカウントでログインします
3. カタログデータのダウンロードが始まります。完了すると地図などの画面に進みます

- ダウンロードするデータは約600MBです。Wi-Fiの安定した環境で実行してください
- セットアップ中はアプリを閉じないでください
- Webカタログのお気に入りも、このときに取り込まれます

### サンプルデータで試す

Circle.ms のアカウントがなくても、起動時に「サンプルデータではじめる」を選ぶと、内蔵のサンプルデータで操作を試せます。
あとから設定画面の「セットアップする」で Circle.ms のデータに切り替えられます（サンプルデータは削除されます）。

## 画面の構成

画面下のタブで4つの画面を切り替えます。

| タブ | できること |
|---|---|
| 地図 | 日程・ホールごとに、お気に入りサークルを並べた地図を作る |
| サークル一覧 | 日程 → ブロックの順に絞り込んで、サークルを網羅的にチェックする |
| お気に入り | お気に入り登録したサークルだけを日程ごとに確認する |
| 検索 | サークル名やペンネームからサークルを探す |

どの画面でもサークルを選ぶと、右側に詳細が表示されます。

## 地図を作る

### 1. ホールを選ぶ

地図画面のツールで「ホール選択」から日程とホールを選びます。東123のようなホール全体のほか、東1のような1ホール単位でも地図を作れます。地図は「日程×ホール」ごとに別々に保存されます。

### 2. 自動配置された地図を確認する

地図を開くと、お気に入りサークルが自動で配置されます。並べ直したいときは、ツールの「サークルを自動配置」を使います（回転や表示形式はそのまま引き継がれます）。

### 3. サークルやホール画像を動かす

サークルやホール画像はドラッグで動かせます。動かす対象（サークル／ホール画像）を切り替えたり、「固定」にして誤って動かさないようにしたりできます。
操作を間違えたときは、「取り消す」「やり直す」で戻せます。

### 4. サークルの向きと表示形式を変える

地図上のサークルを選ぶと、「回転」と「表示形式」のボタンが表示されます。

- **回転**: サークルを90度回転します。縦長の島の横など、狭い場所に収めるときに使います
- **表示形式**: そのサークルだけ表示形式を変えます。「地図設定に従う」を選ぶと、地図全体の設定に戻ります

線が伸びている辺にサークルをくっつけて置くと、線がカードの角から伸びるようになります。

### 5. 用紙と表示を設定する

ツールの「用紙・表示」で、地図全体の設定を変えられます。

| 設定 | 内容 |
|---|---|
| 用紙サイズ | A3・B4・A4・B5 |
| 用紙の向き | 縦・横 |
| 用紙分割 | 1枚、横に2枚、縦に2枚 |
| 線の太さ | ホール上のスペースからサークルへ伸びる線の太さ |
| サークル表示形式 | 地図全体の表示形式（カットの大きさ違い、カット＋サークル名、詳細、1行など8種類） |
| ジャンル画像透明度 | 地図に重ねるジャンル表示の濃さ |
| スタンプ表示・訪問済マーク表示 | 地図にスタンプ・訪問済みマークを出すかどうか |

「個別の表示形式をリセット」で、サークルごとに変えた表示形式をまとめて地図全体の設定に戻せます。

### 6. 表示するお気に入り色を選ぶ

ツールの「表示する色」で、地図に出すお気に入り色を選べます（最大18色）。日程や目的ごとに、見たいサークルだけの地図を作るときに使います。

### 7. 画像に書き出して印刷する

ツールの「地図を画像に書き出す」で、用紙サイズに合わせた印刷用の画像を作れます。書き出した画像は、共有メニューから写真への保存やプリント、ほかのアプリへの送信ができます。
用紙分割をしている場合は、用紙1枚ずつの画像に分けて書き出されます。

## サークルをチェックする

サークルを選ぶと表示される詳細では、次のことができます。

- お気に入り登録・お気に入り色の変更
- メモ（お気に入り登録したサークルのみ）
- スタンプ（5種類）・訪問済みの記録。地図にも表示されます
- pixiv・X の起動、メロンブックス・フロマージュでの検索

お気に入り色の名前は、設定の「お気に入り名称設定」で自由に変えられます。

## Webカタログとお気に入りを同期する

設定の「Webカタログ連携」で、Webカタログとお気に入りをやり取りできます。

- **Webカタログから受信**: Webカタログで登録したお気に入りをアプリに取り込みます
- **Webカタログへ送信**: アプリで登録・変更したお気に入りをWebカタログに反映します

スタンプと訪問済みはアプリ内だけの記録で、Webカタログには送信されません。

## カタログデータを更新する

設定の「カタログデータ」から、最新のデータに更新できます。

- **カラーカット・サークル情報の更新**: カットやサークル情報を最新のデータに更新します

更新はボタンを押したときだけ行われます。アプリが自動でダウンロードすることはありません。
