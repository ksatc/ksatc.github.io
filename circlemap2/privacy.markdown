本アプリケーション「CircleMap2」（以下「本アプリ」）における利用者情報の取扱いについて説明します。

## 1. 取得する情報と保存場所

- **Circle.msから取得する情報**
  - コミケWebカタログ（Circle.ms）の公式 API を利用し、OAuth認証を通じてアクセストークン、サークル情報、お気に入り、メモを取得します。
- **アプリ内で作成する情報**
  - 地図のレイアウトや設定、保存した地図画像です。
- **利用状況に関する情報**
  - Firebase Analytics（Google）により、画面表示・機能の利用状況、端末の機種、OS・アプリのバージョン、アプリインスタンスIDなど、個人を特定しない情報を収集します。
  - サークル情報やお気に入り、メモの内容は含まれません。

Circle.msから取得する情報とアプリ内で作成する情報は、利用者の端末内にのみ保存され、開発者のサーバーには送信されません。端末内のデータは、本アプリを削除すると消去されます。

## 2. 利用目的

- 本アプリの機能の提供（Webカタログデータの表示、お気に入りの同期、地図作成など）
- 利用状況の把握による、品質向上および新機能の検討

## 3. 外部への送信

法令に基づく場合を除き、取得した情報を利用者の同意なく第三者へ提供することはありません。ただし、以下の送信が行われます。

- 利用者の操作に基づき、お気に入り情報等が [Circle.ms](https://webcatalog.circle.ms/) へ送信されます。
- 利用状況に関する情報が、Firebase Analytics を通じて Google へ送信されます（[Firebaseのプライバシーについて](https://firebase.google.com/support/privacy)）。

本アプリからリンクする外部サイト（pixiv、Xなど）における情報の取扱いについては、各サイトのプライバシーポリシーをご確認ください。

## 4. 免責事項

本アプリの利用により発生したいかなる損害についても、コミケット準備会およびCircle.msは一切の責任を負いません。

## 5. 変更・お問い合わせ

本ポリシーは必要に応じて変更することがあり、変更後の内容は本ページに掲載した時点で効力を生じます。
